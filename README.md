# Data for cloud sessions

Archives of the trade bot's data (asx-bot), for Claude Code cloud sessions. Unzip each into place:

- ibkr_1..5_*.zip: IBKR 1-minute history, one folder per stock code, 2026-03-26 to 2026-09-25
  (the replay's history dir - on Rick's PC %LOCALAPPDATA%\asx-bot\ibkr\history)
- ibkr_6_index.zip: the ASX 200 index (^AXJO) 1-minute history, same folder
- announcements.zip: data/announcements (history, cache, live, pages; the PDFs are left out)
- prices_1.zip, prices_2.zip: data/prices/yfinance
- events_universe_arena.zip: data/events, data/universe, data/arena

40,580 of the 40,594 history files (14 were open in the live download when archived). 26 Sep 2026.
