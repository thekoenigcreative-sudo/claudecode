These are copies of the `AGENTS.md` files that live in each trader agent's OpenClaw
workspace, kept in the repo so they are versioned and reviewable alongside the code that
prompts them.

| Agent | Live location |
|---|---|
| `trader-reader` | `~\.openclaw\workspace-trader-reader\AGENTS.md` |
| `trader-decider` | `~\.openclaw\workspace-trader-decider\AGENTS.md` |
